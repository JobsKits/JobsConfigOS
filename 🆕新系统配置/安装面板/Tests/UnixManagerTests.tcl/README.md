## 🔥 <span id="前言">前言</span>

使用开发机已有 Tcl 8.6+ 与 `/bin/sh` 检查 GUI 的数据和异步进程合同。无需 Tk 或显示服务器，不调用真实 apt/dnf/apk/pkg，不写系统状态。

```sh
tclsh './UnixManagerTests.tcl'
```

覆盖十语字段/占位符、数据偏好不执行、缺失/重复清单、未知/空选写入拒绝、单批命令与精确 ID、参数含中文空格和 Shell 字符、输出分片/EOF/真实非零退出码、延迟完成/仍活跃保护、重复任务拒绝和完整日志。临时现场位于系统临时目录，输出实际路径；不删除测试现场。

源码模块加载、模型事件循环和假子进程不代替实际 Tk 控件及六平台桌面/PolicyKit/字体/包事务验收。
