## 🔥 <span id="前言">前言</span>

管理面板专用内部执行器，不是用户安装入口。由 Tcl 模型传入已建立的私有状态文件和完整命令参数；原样执行一次，等待命令结束，将0至255的真实退出码写回，并以同码退出。没有提权、网络、包管理器、重试或强杀逻辑。

标准输出与错误由 GUI 管道收集，完整后台输出写到本次 `session-*`；后端保留自己的业务日志。模型在输出 EOF 后核对状态并回收直接子进程；状态缺失/异常一律未完成，不当成功。运行依赖系统 `/bin/sh`，单独执行参数不足即退出2。
