## 🔥 <span id="前言">前言</span>

以 [**Tcl/Tk**](https://www.tcl-lang.org/) 原生桌面控件管理当前平台的组件。保留既有 CLI、包映射与受管收据机制，不扩大为 MacOS 专属功能。

## 一、<span id="usage">启动</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

```sh
sh './【Debian】🧰新系统配置管理.sh'
```

从本包目录执行上例；完整多平台目录可以复制、改名或放在中文空格路径，从其它工作目录启动。只复制本入口不够，共享资源由入口自身位置解析到 `../../安装面板/`，后端位于同平台原脚本包。

需要 Tcl/Tk 8.6+、图形桌面和 `DISPLAY`（Wayland 需要 XWayland）。缺少 Tk 时由管理员审阅来源后执行 `apt-get install tk`；启动器仅提示，不自动安装、提权或改动软件源。无桌面的服务器继续使用[终端入口](../【Debian】🆕新系统配置.sh/README.md)。

`--help` 查看说明；`--check` 只核对交付资源与目标系统，不创建日志或收据、不启动 GUI。普通启动以 nohup 脱离启动终端后快速返回，不关闭用户已有 Shell；失败诊断保存在状态目录 `launch.*`，终端会显示实际路径。GUI 只调用 `--list`，不执行安装；界面每次查询会在当前用户状态目录保存自己的会话日志。

## 二、<span id="behavior">选择与执行</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

默认空选，整行勾选、Tab/空格、多选、搜索、选中可见项和清空。切换安装/卸载、主题和语言保留当前勾选。先点“预览计划”，成功后当前选择的主操作按钮才可用；选择或操作变化会取消旧计划授权。查询失败/无匹配有完整空态和重新加载入口。

主操作按钮是最终确认，只把显式 ID 一次性交给 CLI，附带其既有 `--yes` 接口。非 root 会话只有执行时才尝试 [**PolicyKit**](https://www.freedesktop.org/software/polkit/docs/latest/pkexec.1.html) `pkexec` 原生授权；未安装或桌面认证不可用时明确失败，用户可在已授权的管理员会话启动或改用原有 sudo CLI。不会在不可见终端等待 sudo 密码。管理员会话内的运行数据归该会话用户。

后端保持原有目标系统门禁、依赖健康检查、补缺/修复、互斥、归属和共享依赖保护；不全量升级、不抢锁。卸载页的预览只报告当前健康，卸载资格在执行时按收据核验；不把预览成功当成可卸载凭据。GUI 不解释后端中文文案为成功事件：它按真实退出码显示“批处理完成/未完成”，逐项新装、复用、保留及失败详见原始日志。后端无结构化逐项事件，界面不会给所有组件伪造同一个成功/失败结果。执行中锁定选择及重复执行，显示活动指示和真实耗时；不提供强杀包管理器的停止按钮。

## 三、<span id="preferences">主题、语言、日志与生命周期</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

三主题（白天/黑夜/跟随系统）与十语（简体、繁体、藏文、英文、日文、法文、西班牙文、德文、俄文、韩文）及系统语言。默认跟随系统；偏好保存到 `${XDG_STATE_HOME:-$HOME/.local/state}/jobs-new-system-gui/Debian/preferences.dict`，下次恢复。勾选只在当前会话保留。跟随系统每3秒检查 GNOME 的 color-scheme/gtk-theme 或 KDE 的 kdeglobals；环境 `GTK_THEME` 明确指定时优先遵守。其它 X11 桌面没有通用外观协议时沿用 Tk 启动外观，不能承诺任意桌面自动感知。藏文显示依赖系统提供相应字体，字体缺失不会联网代装。

日志上下分隔可拖动，独立滚动；默认追尾，手动浏览自动暂停，再勾选恢复。显示区上限5000行；“复制显示区日志”明确仅复制可见保留文本。“日志文件”打开当前一次查询/执行的完整后台输出，路径位于同状态目录 `session-*`，后端的系统级日志与收据路径仍以终端说明为准。日志白天浅底深字、黑夜深底浅字；原始诊断不翻译。无日志查看器时显示真实文件路径。

关闭执行中的窗口直接最小化，原窗口/事件循环/worker/计时和日志保留，任务完成后仍保持后台；从桌面任务栏恢复同一窗口。空闲关闭询问最小化、取消或完全退出，默认焦点最小化；仅明确空闲退出释放资源。此 Tk 版本使用桌面任务栏最小化，**没有托盘图标**，不伪称 macOS 状态栏/Windows 托盘能力；不注册自启动或系统服务。多个窗口可以只读并存，写操作由后端互斥保护。
